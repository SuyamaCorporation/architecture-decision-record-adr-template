# Architecture Decision Record (ADR) Template

Fill-in-the-blank ADR template for documenting software architecture decisions with context, decision drivers, options compared, consequences, and implementation notes.

## Features
- Structured ADR form: number, title, date, status, deciders, tags
- Decision drivers list (expandable)
- Options considered with pros/cons comparison
- Positive and negative consequences lists
- Preview mode outputs Markdown-formatted ADR
- Multiple ADR save/load via localStorage with named slots
- Print/export support
- Status badges: Draft, Proposed, Accepted, Deprecated, Superseded

## Usage
Fill in the context and decision fields, add decision drivers and options considered with pros/cons, then record consequences. Click Preview to see the Markdown output. Save to persist the ADR.

## Tech
- Tailwind CSS CDN
- Vanilla JS
- localStorage
